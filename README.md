# Digital Building Process

A lightweight multilingual static website for the Digital Building Process research group at TU Wien.

## Commands

```sh
npm install
npm run dev
npm run build
```

The site is built with Astro and Tailwind CSS. The default language is English; German and Japanese are available at `/de/` and `/ja/`.

## GitHub Pages

The intended repository is `Digital-Building-Process-TU-Wien.github.io`, which serves the site at:

`https://digital-building-process-tu-wien.github.io/`
